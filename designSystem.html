token Design Tokens Directory

Token Variable Category Value Description
--primary Brand Color #eb5553 Primary action color, key icons, active state indicators.
--primary-hover Brand Color #d84543 Darker coral for button hover and active pressed states.
--foreground Typography #372d5d Dark indigo for high-contrast headings and primary text.
--foreground-light Typography #514382 Medium indigo for body text and descriptive paragraphs.
--muted-foreground Typography #6d6684 Slate indigo for labels, captions, and secondary metadata.
--accent Surface #fdecec Light coral wash for badges, callouts, and completed steps.
--secondary Surface #f4f2f8 Neutral soft background for card containers and badges.

--ring Accessibility rgba(235, 85, 83, 0.25) Focus ring halo for inputs, selects, and keyboard navigation.
--radius-2xl Border Radius 1.5rem (24px) Corner radius for modals, featured event card, hero banner.
--shadow-xl Elevation 0 20px 35px -5px ... High-elevation shadow for floating modal dialogs and toasts.
--container-max-w Layout 80rem (1280px) Maximum content container width across the platform.
